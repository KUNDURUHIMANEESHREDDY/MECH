## 2. Logic Chain

1. **Test Runner Portability**:
   - `conftest.py` adds only `backend/` to `sys.path`.
   - Python modules throughout `backend/` use absolute imports like `from backend.storage import ...` and `from backend.repository...`.
   - Therefore, running `pytest tests/pytest` without `PYTHONPATH=".;backend"` fails at import time during collection (Observation 2). Adding `pythonpath = . backend` to `pytest.ini` and updating `conftest.py` resolves this collection crash.
2. **Deterministic Mock Fallbacks**:
   - `test_ioi_pipeline_runs` calls `IOIReproductionPipeline(mock_mode=True).run()`.
   - `ioi_pipeline.py` searches for subject and indirect object tokens in `adapter.get_logits(prompt)["top_tokens"]`.
   - `GPT2Adapter._KNOWN_TOP_TOKENS` does not include IOI prompts, returning `" the"`.
   - This causes `ioi_pipeline` to return `status="unavailable"`, omitting `observed_metrics` and `manifest_id` (Observation 4).
   - This single omission cascades to 4 failing test cases (Failures 4, 7, 8, 10).
3. **Defensive Error Handling in AI Scientist Engine**:
   - `ai_scientist_engine.py` accesses `val_res["confidence"]["confidence_score"]` without checking if `"confidence"` exists in `val_res` (Observation 4).
   - Because `validation_engine.validate_discovery` returns `status="unavailable"` when no live candidate is passed, `val_res["confidence"]` raises `KeyError` (Failure 12).
4. **Contract Synchronization in Tests**:
   - Evidence policy and reporting were hardened to prevent synthetic data fabrication.
   - Older tests in `test_evidence_persistence.py`, `test_sprint2_deliverable.py`, and `test_validation_loop.py` asserted outdated contracts:
     - Expecting synthetic text `"Layer 8 Pause"` in `ReportService` output (Failure 9).
     - Expecting minimality to be unmeasured (`0.0`), when live execution actually measures it at `0.9` (Failure 13).
     - Expecting old trace dictionaries without live provenance to yield evidence nodes (Failures 1, 2, 3).
     - Expecting discovery state to be `"Publication"` when discovery engine leaves publication to the `Scribe` agent (Failures 6, 11).
