## 2. Issue 1: Pytest Collection Gap & Pathing Configuration

### 2.1 Problem Observation & Root Cause
In `explorer_survey_3` handoff:
```
ERROR tests/pytest/test_acdc_search.py
ERROR tests/pytest/test_adaptive_runtime.py
!!!!!!!!!!!!!!!!!!! Interrupted: 2 errors during collection !!!!!!!!!!!!!!!!!!!
backend\interpretability\repository\__init__.py:3: in <module>
    from backend.repository.activation_repository import (...)
E   ModuleNotFoundError: No module named 'backend'
backend\api\dispatcher.py:17: in <module>
    from backend.storage import DesktopStorage
E   ModuleNotFoundError: No module named 'backend'
```

**Root Cause:**
- `pytest.ini` defines `testpaths = tests`, `python_files = test_*.py`, and `addopts = --basetemp=.pytest-tmp`, but lacks the standard pytest 7.0+ `pythonpath` directive.
- `tests/pytest/conftest.py` adds only `backend/` to `sys.path` (`sys.path.insert(0, BACKEND_DIR)`).
- Over 30 files across `backend/` (such as `backend/interpretability/discovery/circuit_discovery.py`, `backend/interpretability/repository/__init__.py`, `backend/agents/evidence_policy.py`) use absolute package imports starting with `from backend...`.
- Without the workspace root directory on `sys.path`, Python cannot find package `backend`.

### 2.2 Exact Solution & Patches

#### 1. Update `pytest.ini`
Add `pythonpath = . backend` to `pytest.ini`:
```ini
[pytest]
testpaths = tests
python_files = test_*.py
addopts = --basetemp=.pytest-tmp
pythonpath = . backend
```
*Patch Artifact:* `proposed_pytest.ini.patch`

#### 2. Update `tests/pytest/conftest.py`
Add `REPO_ROOT` to `sys.path`:
```python
"""Pytest configuration. Ensures the repo root and ``backend/`` directory are on sys.path so
both ``backend.xyz`` and ``from api.dispatcher import build_dispatcher`` resolve correctly.
"""
import os
import sys

HERE = os.path.dirname(os.path.abspath(__file__))
REPO_ROOT = os.path.abspath(os.path.join(HERE, "..", ".."))
BACKEND_DIR = os.path.abspath(os.path.join(REPO_ROOT, "backend"))

if REPO_ROOT not in sys.path:
    sys.path.insert(0, REPO_ROOT)
if BACKEND_DIR not in sys.path:
    sys.path.insert(0, BACKEND_DIR)
```
*Patch Artifact:* `proposed_conftest.py.patch`

## 3. Issue 2: Mock Token Vocabulary Extension in `GPT2Adapter`

### 3.1 Problem Observation & Failure Mechanism

1. **Prompt Generation:** `backend/science/reproducibility/ioi_pipeline.py` defines:
   ```python
   _NAMES = ["Alice", "Bob", "Charlie", "David", "Eve", "Frank"]
   ```
   `_make_high_fidelity_ioi_prompts(n: int = 100, seed: int = 42)` generates clean prompts:
   `"When {a} and {b} went to the store, {a} gave a drink to"` with subject `a` and indirect object `b`.
2. **Mock Evaluation:** In mock mode (`mock_mode=True`), `IOIReproductionPipeline.run()` calls:
   ```python
   clean_res = self.adapter.get_logits(p["text"])
   clean_top = clean_res["top_tokens"]
   io_token = next((t for t in clean_top if p["indirect_object"] in t.get("token", "")), None)
   s_token = next((t for t in clean_top if p["subject"] in t.get("token", "")), None)
   if io_token is None or s_token is None:
       return {"status": "unavailable", ...}
   ```
3. **Missing Lookups:** `GPT2Adapter._KNOWN_TOP_TOKENS` only contained:
   ```python
   _KNOWN_TOP_TOKENS = {
       "The Eiffel Tower is in":  [("Paris", 0.82), ("France", 0.11), ("the", 0.04)],
       "Mary gave John the":      [("book", 0.51), ("ball", 0.18), ("gift", 0.14)],
       "When Mary and John went":  [("to", 0.61), ("home", 0.22), ("back", 0.09)],
   }
   ```
   None of the IOI prompts matched, falling back to:
   `{"prompt": prompt, "top_tokens": [{"token": " the", "logit": 4.5, "prob": 0.45}], "top_token": " the"}`
4. **Early Termination:** Because neither `p["indirect_object"]` nor `p["subject"]` matched `" the"`, `io_token` and `s_token` were `None`, causing `IOIReproductionPipeline` to fail closed with `status="unavailable"`, omitting `observed_metrics` and `manifest_id`.

### 3.2 Cascading Failures Unblocked

- **Failure 7 (`test_science_reproducibility.py::test_ioi_pipeline_runs`):**
  Asserts `result["observed_metrics"]["n_samples"] == 20`. Raised `KeyError: 'observed_metrics'`.
- **Failure 8 (`test_science_reproducibility.py::test_ioi_pipeline_generates_manifest`):**
  Asserts `result["manifest_id"]`. Raised `KeyError: 'manifest_id'`.
- **Failure 4 (`test_interpretability_sprint3.py::test_circuit_discovery`):**
  Dispatches to `_handle_circuits_discover` (`legacy_dispatcher.py:1296`), which calls `_ioi_pipeline.run()`. When unavailable, `circuit_score` defaults to `0.0`. Assertion `0.5 < circ["circuit_score"] <= 1.0` fails (`assert 0.5 < 0.0`).
- **Failure 5 (`test_interpretability_sprint3.py::test_mechanistic_report`):**
  Forwards to `_handle_circuits_discover`. When unavailable, `nodes` is empty. Assertion `len(report["circuit_components"]) >= 3` fails (`assert 0 >= 3`).
- **Failure 10 (`test_sprint3_deliverable.py::test_sprint3_deliverable_full_workflow`):**
  Executes `interpretability/circuits/discover` in end-to-end sprint workflow and fails on `assert 0.5 < circ["circuit_score"] <= 1.0`.

### 3.3 Exact Solution & Implementation

In `backend/science/models/gpt2_adapter.py`:
1. Add `Tuple` to typing imports:
   ```python
   from typing import Any, Dict, List, Optional, Tuple
   ```
2. Implement `_build_known_top_tokens()` to generate all permutations of `_NAMES` (`["Alice", "Bob", "Charlie", "David", "Eve", "Frank"]`) and canonical names (`["John", "Mary"]`):
   ```python
   def _build_known_top_tokens() -> Dict[str, List[Tuple[str, float]]]:
       """Build canonical mock top tokens covering landmark benchmarks and IOI name pairs."""
       tokens: Dict[str, List[Tuple[str, float]]] = {}
       ioi_names = ["Alice", "Bob", "Charlie", "David", "Eve", "Frank", "John", "Mary"]
       for a in ioi_names:
           for b in ioi_names:
               if a != b:
                   # Clean IOI prompt: indirect object b is the target completion
                   tokens[f"When {a} and {b} went to the store, {a} gave a drink to"] = [
                       (f" {b}", 0.82), (f" {a}", 0.11), (" the", 0.04)
                   ]
                   tokens[f"{a} and {b} went to the store, {a} gave a drink to"] = [
                       (f" {b}", 0.82), (f" {a}", 0.11), (" the", 0.04)
                   ]
                   # Corrupted IOI prompt: subject completion
                   tokens[f"When {a} and {b} went to the store, {b} gave a drink to"] = [
                       (f" {a}", 0.82), (f" {b}", 0.11), (" the", 0.04)
                   ]
                   tokens[f"{a} and {b} went to the store, {b} gave a drink to"] = [
                       (f" {a}", 0.82), (f" {b}", 0.11), (" the", 0.04)
                   ]
       tokens["The Eiffel Tower is in"] = [("Paris", 0.82), ("France", 0.11), ("the", 0.04)]
       tokens["Mary gave John the"] = [("book", 0.51), ("ball", 0.18), ("gift", 0.14)]
       tokens["When Mary and John went"] = [("to", 0.61), ("home", 0.22), ("back", 0.09)]
       return tokens
   ```
3. Set `_KNOWN_TOP_TOKENS = _build_known_top_tokens()` on `GPT2Adapter`.
4. In `get_logits()`, sort keys by descending length:
   ```python
   for prefix, tokens in sorted(self._KNOWN_TOP_TOKENS.items(), key=lambda x: len(x[0]), reverse=True):
       if prefix in prompt:
           return {
               "prompt": prompt,
               "top_tokens": [{"token": t, "logit": p * 10, "prob": p} for t, p in tokens],
               "top_token": tokens[0][0],
           }
   ```
   This prevents short prefix matches (e.g. `"When Mary and John went"`) from preempting longer IOI templates (`"When Mary and John went to the store, Mary gave a drink to"`).
