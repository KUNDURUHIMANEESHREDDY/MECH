# Mechanistic Understanding Documentation (Sprint 3)

Details the understanding layer: Circuit Discovery, Causal Tracing, Attribution Patching, Feature Labeling, Polysemanticity, Clustering, and Mechanistic Reports.

---

## Capabilities
1. **Automated Circuit Discovery**: Graph extraction (`Neuron ➔ Feature ➔ Attention Head ➔ Output`).
2. **Causal Tracing**: Clean vs corrupted prompt causal effect curve computation.
3. **Attribution Patching**: Fast gradient-based attribution candidate screening.
4. **Automated Feature Labeling**: LLM-assisted semantic feature interpretation.
5. **Polysemanticity Detection**: Graded polysemanticity scoring.
6. **Feature Clustering**: Cosine similarity & co-firing feature clustering.
7. **Mechanistic Reports**: Structured explanations referencing evidence DTOs.
